# ai-search

[English](README.md) · **Русский**

Локальный поиск **по смыслу** в прошлых переписках с ИИ-агентами (Claude Code, Codex, Gemini CLI, Antigravity) и в файлах ваших проектов. Агент вызывает его командой `/search`. Всё работает на вашем Mac, ничего не отправляется в интернет.

На запрос «как я проверял, выдержит ли сервер много пользователей» он найдёт сессию про «нагрузочное тестирование на Locust», хотя слов из вопроса в ней нет.

## Установка

Требования: macOS на Apple Silicon (M1 и новее), примерно 5 ГБ свободного места, интернет на время установки.

```bash
git clone https://github.com/xerottin/ai-search-vector.git ~/ai-search
cd ~/ai-search
./install.sh
```

Обновление: `cd ~/ai-search && git pull && ./install.sh`.

Скрипт сделает всё сам. Займёт это примерно 5–10 минут:

1. Поставит `uv` (менеджер Python) через Homebrew, а если его нет, через официальный установщик.
2. Создаст отдельное окружение `.venv` с Python 3.12 и библиотеками. Системный Python не трогается.
3. Скачает модель эмбеддингов `BAAI/bge-m3` (около 2.3 ГБ, один раз).
4. Проиндексирует переписки с агентами.
5. Добавит команду `ai-search` в `~/.local/bin`, чтобы она работала из любой папки.
6. Запустит фоновую службу с автозапуском при входе в систему. Файлы проектов она доиндексирует сама, начиная с самых свежих.
7. Добавит команду поиска агентам, которые установлены:
   - Claude Code: `/search <вопрос>`
   - Codex: `$search <вопрос>`
   - Gemini CLI: `/search <вопрос>`

Если macOS спросит «python хочет получить доступ к папке Рабочий стол», нажмите **Разрешить**.

## Использование

В агенте:
```
/search как я настраивал traefik
```

Из терминала:
```bash
ai-search search "как я настраивал traefik"
ai-search search "ошибка с CORS" --kind chats    # только переписки
ai-search search "отправка СМС" --kind files -n 5 # только файлы, 5 результатов
ai-search search "..." --json                    # для скриптов
```

Управление:
```bash
ai-search status          # что проиндексировано, работает ли служба, прогресс
ai-search index           # вручную проверить изменения
ai-search index --full    # построить индекс заново
ai-search stop | start | restart
ai-search logs            # журнал службы
./uninstall.sh            # удалить всё
```

## Как это работает

```
 Переписки агентов               Файлы проектов (~/Desktop)
 ~/.claude/projects/*.jsonl      код, .md, .txt, PDF, DOCX
 ~/.codex/sessions/*.jsonl       (без node_modules, .git, venv,
 ~/.gemini/…                      build, тестов, секретов)
            │                               │
            └───────────────┬───────────────┘
                            ▼
              разбор → куски по ~1500 символов
              → маскировка секретов (ключи, токены, пароли)
              → удаление дублей
                            ▼
          модель bge-m3 (локально) → вектор смысла
                            ▼
          ~/.ai-search/index.db  (SQLite)
          ├── sqlite-vec: векторы, поиск по смыслу
          └── FTS5:       поиск по точным словам
```

**Как индекс остаётся свежим:**

- **А. Фоновая служба.** macOS через FSEvents сообщает об изменениях в папках. Служба ждёт 5 секунд после последнего изменения файла (20 секунд для переписок) и переиндексирует только этот файл. Удалённые файлы убирает из индекса. Новые файлы обрабатываются вне очереди, даже во время большой индексации.
- **Б. Проверка перед поиском.** Перед каждым поиском сверяются даты изменения файлов, и всё новое, если его немного, доиндексируется сразу. Это страховка на случай, если служба была выключена или Mac спал.

**Как идёт поиск.** Поиск по смыслу и поиск по словам выполняются вместе. Результаты объединяются методом RRF, и в выдачу попадают 10 лучших кусков со ссылкой на источник. Один вызов `/search` обычно стоит агенту около 8–20 тысяч токенов. Сама индексация токенов не тратит.

## Настройка

Всё задаётся в `config.toml`. После изменений выполните `ai-search restart`.

- `file_roots`: какие папки индексировать (по умолчанию `~/Desktop`).
- `exclude`: что пропустить, например `["old", "*/label-studio"]`.
- `[chats]`: где лежат переписки агентов.

## Где что лежит

| Что | Где |
|---|---|
| Программа | эта папка (`.venv` внутри) |
| Индекс и журналы | `~/.ai-search/` |
| Модель | `~/.cache/huggingface/hub/models--BAAI--bge-m3` |
| Команда в терминале | `~/.local/bin/ai-search` (ссылка) |
| Фоновая служба | `~/Library/LaunchAgents/com.local.ai-search.plist` |
| Команды агентов | `~/.claude/skills/search`, `~/.codex/skills/search`, `~/.gemini/commands/search.toml` |

## Ограничения

- Antigravity хранит сами диалоги в закрытом формате. Индексируются только его планы и отчёты (`brain/*.md`).
- Первая индексация большого Desktop может занять около часа в фоне (примерно 14 кусков в секунду на M2 Pro). Поиск работает сразу, а файлы добавляются постепенно.
- Секреты маскируются по шаблонам: ключи API, токены, пароли, приватные ключи. Файлы `.env`, `*.pem` и `*.key` не читаются совсем. Шаблоны покрывают не всё, поэтому не храните секреты в обычных заметках.
